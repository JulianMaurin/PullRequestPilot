## Post-fix review round (regressions in the fix wave itself)

All confirmed by adversarial verification, all fixed before commit:

1. Load-more sentinel retried a failed page in a tight loop (offline/rate-limit)
   — sentinel now gated on `state.error == nil`; a refresh re-arms it.
2. Superseded PRFetcher refresh wrote `isLoading=false` into the successor's
   fresh state — cancelled paths no longer touch state at all.
3. Superseded PRFetcher tasks wrote the old query's error/toast into the fresh
   state — generic catches guard on `Task.isCancelled` (loadMore still clears
   its own `isLoadingMore`, since a refresh cancels it without replacing state).
4. performLoadMore committed after the unguarded `filter` suspension — gate
   duplicated post-filter.
5. Residual reset-vs-refresh race (refreshAll child holding a pre-edit view
   snapshot) — pending-task joins now keyed on (view, query); a mismatched
   pending fetch is cancelled instead of joined.
6. GatedGitHubClient parked continuations forever on a missed interleaving,
   hanging the whole run — added drain latch + per-test watchdog.
7. (verification) committed ReviewQueueView content built standalone via stash.

Rejected on review: MockHTTPSession deinit lifetime hazard (lexical lifetimes
since Swift 5.7 make it unreachable); WidgetDataMappingTests global-override
race (all users are MainActor; save+load are a single non-suspending job).

## Notes

- FINDING-011 was fixed by **deleting** the `pullrequestpilot://pr?url=`
  passthrough rather than validating it: nothing in the repo or widget emits
  such links, and the registered scheme made it a confused-deputy primitive
  for any local process or webpage.
- The widget entitlement removal (FINDING-019) regenerates
  `PullRequestPilotWidget.entitlements` from `project.yml`; both are committed
  together. Widget entitlements remain a strict subset of the main app's.
- `ReviewQueueView.swift` carried unrelated in-progress work (narrow-width
  layout mode). Only the audit hunks were staged and committed; the
  narrow-mode change remains uncommitted in the working tree, byte-identical
  to its pre-audit state.
- The review-queue commit spans two root causes (pagination + ux) in one file;
  hunks were not separable without breaking compilation. Flagged per the
  commit-shaping contract.
- Test count: 605 → 651 (46 added/rewritten).
