1.3.0

September 25, 2026 Latest

Act on pull requests without leaving the app, and get to the right view from anywhere.

New

  • Drafts: convert a pull request to a draft, or mark it ready for review, from its right-click menu.
  • Exclude from a view: right-click a pull request, repository or organization to exclude its author, label, repository or organization from the view.
  • Straight to the view: clicking a widget opens its view, and clicking a notification opens the view and the pull request it announced.
  • New pull request count: the menu bar icon shows how many pull requests are new, and each view has its own bell for notifications.
  • Required checks: the detail panel marks the checks required to merge, and the reviewers section can be collapsed.
  • Narrow windows: below a certain width the list uses a single pane, with the detail panel underneath.
  • Open in cmux, next to VS Code and iTerm, all grouped under a new “Open in” submenu.
  • Menu commands: New View (⌘N), Delete View, Refresh (⌘R), and Show Next or Previous View (⌘] and ⌘[).
  • Diagnostics: Help › Export Logs… saves a log file to attach to a bug report.

Improved

  • Errors show as short notices, and problems that need you stay on a banner until they're fixed. The banner clears itself once things recover.
  • Refresh pauses while your Mac sleeps or is offline and resumes when it's back, and it keeps every page of results you've loaded.
  • GitHub rate limits are waited out, with your results left on screen.
  • Token setup explains what a fine-grained token needs and warns when a classic token lacks the repo scope.
  • A git folder on a disconnected disk is kept and used again once the disk is back.
  • Faster avatars, timelines and repository scans.

Fixed

  • A single request rejected by GitHub no longer signs you out. A revoked token asks for a new one and keeps your views.
  • Results that GitHub withholds, for example behind SAML single sign-on, are explained instead of stalling the list.
  • Review states match GitHub: a later comment no longer hides an approval, and a re-requested review shows as awaiting.
  • Re-run checks show their latest attempt.
  • Stacked pull requests are no longer dropped when branches form a loop.
  • Exclude author works for bots, and pull requests from forks are no longer matched to a local branch with the same name.

1.2.1

March 31, 2026
  • Notifications: notification toggles persist when the window is hidden and shown again.
  • Notification setup: the app asks for permission before opening System Settings, so it appears in the Notifications list.
  • Checks: double-click or right-click a check to open it in the browser or copy its URL.
  • Polish: smaller pending-check icons.

1.2.0

March 30, 2026
  • Window menu: reopen a view from the Window menu, with ⌘1, ⌘2, ⌘3 and so on.
  • Single click to open: click the menu bar icon to show the window, right-click for its menu.
  • Offline state: a dedicated icon for network errors instead of the generic warning.
  • Crash fix in the pull request list.
  • Detail panel: closes when the selected pull request leaves the view after a refresh.

1.1.0

March 16, 2026
  • Detail panel: click a pull request to see its activity timeline and each check run.
  • New icons: pull request state and CI icons in GitHub's style replace the status badges.
  • Quick filters: filter by organization, repository, author or label from the context menu.
  • Network resilience: a quick retry at launch when the network isn't ready.
  • Widgets: aligned with the app, with actions in the footer and subtle accent bars.
  • Copy: copied lists include full pull request URLs.
