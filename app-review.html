App Review Notes

GitHub API Usage

This app uses the GitHub GraphQL API on behalf of the authenticated user, using their personal access token. This complies with GitHub's Terms of Service (Section H — API Terms), which permits API access for user-initiated actions. The app does not scrape, cache data beyond the current session, or exceed rate limits. No GitHub data is shared with third parties.

Authentication

The user provides their own GitHub personal access token (created at github.com/settings/tokens with the repo scope). The token is stored in the macOS Keychain and used only to call api.github.com.

To test: paste any valid GitHub personal access token into Settings, then click "Save & Validate".

Data Handling

  • The GitHub token is stored exclusively in the macOS Keychain.
  • Pull request metadata (titles, authors, review states) is fetched and displayed locally, never persisted beyond the current session.
  • No analytics, telemetry, or third-party SDKs are included.
  • The only network communication is with api.github.com.

Core Functionality

  • Monitor GitHub pull request review queues with configurable views and filters.
  • Desktop notifications when new pull requests appear in a view.
  • Widget extension showing PR summaries and details on the desktop.
  • Local repository matching to open PRs in the user's editor.
