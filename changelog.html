Changelog

About updates

Pull Request Pilot is distributed via the Mac App Store. Updates are delivered automatically through the App Store — no manual downloads needed. Make sure automatic updates are enabled in System Settings.

v1.1.0

March 16, 2026
  • PR detail panel — single-click a PR to see its activity timeline and individual CI check run details
  • GitHub-style icons — replaced status badges with PR state icons and CI indicators
  • Context menu filters — quickly filter by org, repo, author, or label
  • Network resilience — quick retry on startup when network fails
  • Widget improvements — aligned with app experience, action buttons moved to footer, subtle accent bars
  • Copy improvement — full PR URLs in copied list format
