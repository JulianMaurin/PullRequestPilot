Privacy Policy

Effective date: March 13, 2026

Pull Request Pilot ("the App") is a macOS application developed by Julian Maurin. This policy describes how the App handles your data.

Data Collection

The App does not collect, transmit, or store any personal data on external servers. All data remains on your device.

GitHub Token

The App requires a GitHub personal access token to function. This token is:

  • Stored locally in the macOS Keychain, protected by the operating system.
  • Sent only to GitHub's API (api.github.com) to fetch pull request data on your behalf.
  • Never transmitted to any other party.

GitHub Data

The App fetches pull request metadata from GitHub (titles, authors, review states, check statuses). This data is displayed locally and cached temporarily in memory. It is not stored permanently, shared with third parties, or used for analytics, tracking, or advertising.

Local Repositories

If you configure local git repository directories, those file paths are stored in the App's sandbox container on your device. The App accesses these directories read-only to match pull requests with local repositories.

Analytics and Tracking

The App contains no analytics, no telemetry, no crash reporting, and no advertising SDKs. No data is sent anywhere except to GitHub's API as described above.

Third-Party Services

The only third-party service the App communicates with is the GitHub API. No other external services are contacted.

Data Deletion

You can delete all stored data at any time by clearing your GitHub token in the App's Settings. This removes the token from the Keychain and clears all cached data. Uninstalling the App removes all remaining local data.

Children's Privacy

The App is not directed at children under 13 and does not knowingly collect data from children.

Changes to This Policy

If this policy changes, the updated version will be posted at this URL with a new effective date.

Contact

If you have questions about this privacy policy, please open an issue on GitHub.
