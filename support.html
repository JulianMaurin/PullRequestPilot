Getting Started

Pull Request Pilot requires a GitHub personal access token with repo scope. You can create one at github.com/settings/tokens. Enter the token in the App's Settings to get started.

Common Questions

Where is my token stored?

Your GitHub token is stored securely in the macOS Keychain. It is never sent anywhere except to GitHub's API.

How do I remove my data?

Go to Settings and click "Clear" next to your saved token. This removes the token from the Keychain and clears all cached data.

How often does the app refresh?

By default, every 60 seconds. You can adjust this in Settings from 30 seconds to 30 minutes.
